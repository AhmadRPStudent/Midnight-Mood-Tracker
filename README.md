Midnight Mood Tracker

A simple and intuitive mood-tracking web application that helps users monitor their daily moods and energy levels.

Midnight Mood Tracker provides a dark-themed interface where users can navigate through their mood entries, add new moods, and view their mood history through a calendar.

Features
Home Page – A welcoming dashboard with quick access to the main sections of the application.
Mood Entries – Access and review recorded mood entries.
Add Mood – Navigate to the section for recording daily moods.
Calendar View – Access a calendar to view mood records by date.
Dark Theme – A modern dark interface with red accent colors for a comfortable visual experience.
Simple Navigation – Easily navigate between different sections of the application.

Design

The application uses a midnight-inspired visual theme:

Background: Dark charcoal and black.
Primary Color: Red/pink accents.
Text: White for readability.
Buttons: Red primary buttons and grey secondary buttons.
Navigation
Section	Description

Mood Entries	Accesses recorded mood entries.
Add Mood	Opens the mood-entry section.
Calendar	Opens the calendar view.
